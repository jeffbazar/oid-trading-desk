## Architecture and clocks

Production describes itself as a **static here.now site**, generated by `dashboard/live_refresh.py`. The blotter reloads the published page every 60 seconds; the other source pages include 120-second meta-refresh. The reload button explicitly says it reloads publication rather than pulling brokerage marks. Peanut's browser component separately polls its published JSON every 15 seconds. Those browser frequencies do not establish equivalent collector frequencies.

The local dashboard must show **collection time, page build, marks, macro judgment, and observation dates separately**. Source data age survives a page reimport. Successful HTTP retrieval does not refresh an embedded quote. The public source-health summary is 5 OK, 25 CARRY, one DISABLED and three NOT_BUILT; it is imported as reported, not recomputed into a claim that feeds are connected locally.

Collection provenance also records its basis. For existing local downloads without a supplied receipt time, file modification time is a labeled proxy rather than independently verified network receipt. A manual fetch records its actual response receipt. Import/normalization time remains another clock.

## Confirmed state and display issues

1. **The reported book is flat.** Rose and Hal open tables are empty and seats are 0/15. The old warning that “one or more open quotes are delayed” remains visible. The new desk can state the flat book clearly without inferring open exposure from that warning.
2. **The session badge is misleading.** The Sunday Oct 4 publication still carries `AFTER-HOURS · LIVE`, while its marks are from Friday. Preserve the imported label in provenance but identify this dashboard as an imported snapshot. A page reload or SSE heartbeat is not market liveness.
3. **P&L summaries mix scopes.** The old header displays Day −$228/−3.2% and Week +$282/+4.0%, while open Shared/Rose totals are $0. The “Closed (all)” table reports 57 rows, cumulative entry debit $73,384, P&L +$14,888.50, 32 wins/24 losses/one flat, and +20.3%. These are reported paper-ledger fields. +20.3% against cumulative ticket debit is not a fund NAV return. Neither account equity, cash flows, settlement verification, fees nor a complete equity curve is provided.
4. **Expired/invalidated rows need their reported status.** The closed section includes more than voluntary closes. Lessons describe some expired tickets using last marks. The importer must not silently convert these into verified settlement proceeds or “correct” P&L without underlying evidence.
5. **Quota presentation conflicts.** The top panel says no `api-quotas.json` yet; its source row reports Oct 4, 4:20 PM PT. FlashAlpha walls explicitly carried after quota reached zero. A new support-map write does not make embedded walls fresh.
6. **Macro values need provenance at point of use.** The strip's Sep 22 Treasury yield and the Oct 2 judgment are separate observations. Production now explicitly explains futures-primary oil and secondary FRED spot. This is not evidence that the macro score used the wrong oil series. Seven input scores support the two discretionary judgments; they are not summed.
7. **Events require current reconciliation.** The retained calendar includes past dates, vendor disagreement for NVDA, and a superseded FlashAlpha MU date replaced by a desk pin. Do not represent a retained calendar or a confidence checkmark as freshly confirmed issuer timing. Preserve conflict notes and source attribution.
8. **Technical data already exists in production.** Chart reports 24 Bullish, six Bearish, five Hold and two UNAVAILABLE rows. SKHY/SPCX lack sufficient 200-bar history; this is not a failed fetch. Values are split-adjusted regular-session USD/share closes. RS is a 20-session return difference versus QQQ/SMH, in percentage points. Forecasts remain null. The new site organizes these existing observations; it does not pretend to add their original computation.
9. **Map is an identity foundation.** Zero edges and zero claims are explicitly intentional; the page lists no relationship collector. Some legal names/exchanges remain unverified. Do not generate customer/supplier edges from ticker similarity, news read-through lists or illustrative capex examples. Funds remain distinct from operating companies.
10. **Intel and news are soft evidence.** Source judgments, watch claims, copied lessons and read-through tickers remain attributable. They do not become independent trade confirmations, validated forecasts, or permission to place orders.

## Local dashboard boundary

The new dashboard reads a normalized import of these public resources through its local API. It provides a Daily Desk, Evidence, Trade journal, Bot Operations and Changes view, ticker/filter drilldowns, provenance, source snapshots, copied operating prompts, and append-only SQLite review notes. Local SSE announces changed snapshot versions or new review records. It does not pull brokerage quotes, install collector schedules, deliver trading decisions to bots, or execute/auto-close positions.

Manual source sync fetches the eight public resources as one import. On a failed collection/import, the previous usable snapshot should remain available. Source data, local review state, proposed feed configuration and the new UI remain separate. Consult `API.md`, `CHANGES.md`, the normalized `data/snapshot.json`, and the original files for the exact implemented interface and current limitations.
