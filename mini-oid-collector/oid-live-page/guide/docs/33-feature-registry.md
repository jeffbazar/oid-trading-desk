## Chart Bot scenarios (shadow source `chart_scenario`, CB-SCN-V1)

Chart Bot publishes `chart-bot/scenarios/latest.json` on the box (daily run plus 3 status refreshes): per ticker a primary and up to 3 alternates with label, direction, calibrated_score, trigger, T1/T2, invalidation, range low/high, ATR distances and status (active, triggered, target_hit, target2_hit, void, expired, held). The box desk-state push (quotes/mirror_poller.py, about every 60 s when the file changes) copies it to the mini at `~/oid-desk/desk/chart-bot/scenarios/latest.json`. The snapshotter reads the primary per ticker and logs `cs_*` columns; the ATR distances are recomputed against the live price each pass. If the file is missing every `cs_*` value is null.

**Calibration warning:** primaries' calibrated_score runs hot (about 44% estimated vs 36% realized, a selection effect). Treat `cs_score` as a ranking, not a probability. Soft colour only: it never elevates a name on its own and is not in any live score.

Replays never read `latest.json` (it would be look-ahead for a past day), so `cs_*` is null in replay rows.
